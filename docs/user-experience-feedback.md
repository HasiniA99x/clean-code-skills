# User experience feedback

Feedback from people who have used the `code-cleanup` skill in a real cleanup session.

## 2026-10-07

Overall, it's a good skill for code cleanup. It's asking for confirmation for each step, which I prefer, and its ensure the behavior of the system will not be changed. It also gives the capability to revert the changes. As an improvement, I would like to suggest considering the doc file changes when cleaning the code.
